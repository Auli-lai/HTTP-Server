🚀 reall_http

基于 epoll + 线程池的 C++11 高性能 HTTP 服务器

📋 功能

  • GET /form — 表单页面
  • POST /submit — 表单提交
  • GET /api/data — RESTful API（JSON）

🔧 API 端点

  • GET /api/data — 列出全部条目
  • GET /api/data/1 — 获取单条
  • POST /api/data — 创建（JSON body）
  • PUT /api/data/1 — 更新
  • DELETE /api/data/1 — 删除

📊 测试

# 压力测试
wrk -t4 -c100 -d30s --latency http://127.0.0.1:8080/index.html

# REST API 测试
curl http://127.0.0.1:8080/api/data
curl -X POST -H "Content-Type: application/json" \
     -d '{"name":"hello"}' http://127.0.0.1:8080/api/data
curl http://127.0.0.1:8080/api/data/1
curl -X DELETE http://127.0.0.1:8080/api/data/1
